Administração

Instalação do agente

Execute em cada máquina (como administrador):

inventario-agente.exe -instalar -servidor {{.D.URL}} -token {{.D.Token}}

Use o IP ou nome da máquina do servidor que as estações enxergam na rede. O agente envia o inventário a cada 4 horas, a cada logon e na inicialização.

Endereço do servidor para os agentes

Defina aqui o endereço fixo que as estações usam para falar com o servidor (ex.: http://10.100.21.114:8080 ou, no futuro, o endereço da nuvem). Se ficar vazio, o instalador usa o endereço pelo qual você abriu o painel — por isso, abrindo em localhost, o agente sairia apontando para localhost. Preencha para corrigir isso.

Baixar o instalador agente v{{.D.VersaoAgente}}

O pacote já vem com o endereço deste servidor e o token preenchidos. Para instalar em uma máquina, descompacte e execute o instalar.bat como administrador.

Baixar pacote (.zip) Só o agente (.exe) Só o config.json

O pacote inclui um modelo para implantação por GPO e o código para gerar um instalador .msi com o WiX Toolset (instruções no LEIA.txt).

Baixar backup do banco

Importar banco de outro servidor

Para levar tudo para um servidor novo (ex.: nuvem): no servidor antigo clique em Baixar backup do banco; aqui, no servidor novo, envie o arquivo. Ele é conferido, o banco atual deste servidor vai para backups\antes-de-importar-… e o servidor reinicia usando o importado — mesmos usuários e senhas, token dos agentes, chamados e inventário. O endereço deste servidor é mantido.

Atualizar o servidor

Versão atual: {{.D.Versao}}. Envie um novo inventario-servidor.exe para aplicar a atualização. O servidor guarda uma cópia da versão anterior (inventario-servidor.antigo.exe), troca o arquivo e reinicia sozinho — o banco de dados é preservado.

Faça um backup do banco antes, por garantia. Se algo der errado, pare o serviço e renomeie inventario-servidor.antigo.exe de volta para inventario-servidor.exe.

Auto-update dos agentes

Quando ligado, cada agente que entra em contato e está numa versão anterior baixa e troca o próprio executável sozinho (na próxima execução da tarefa). Assim, basta atualizar este servidor que as máquinas se atualizam sem reinstalação. O agente contata o servidor a cada 1 hora, no logon e na inicialização — então a frota migra sozinha ao longo de algumas horas / no próximo logon.

Migrar os agentes para outro servidor

Para mudar o servidor de endereço (por exemplo, para a nuvem) sem tocar em cada máquina: informe o novo endereço e o token dele. Conforme cada agente se comunicar com este servidor, ele receberá o aviso e passará a usar o novo — mas só depois de confirmar que o novo endereço responde. Mantenha este servidor no ar até todas terem migrado.

Critérios de nível das máquinas

Define quando uma máquina é OK, Alerta ou Crítica no relatório do painel. A pontuação (máx. 10) soma: geração do processador (0–3), linha i3/i5/i7 (0–2), RAM (0–3) e armazenamento/SSD (0–2).

Padrão: OK ≥ 6, Alerta ≥ 4, Crítico < 4 ou RAM ≤ 4 GB. As regras de pontos podem ser ajustadas no código em uma versão futura, se necessário.
