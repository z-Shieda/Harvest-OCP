Duplicados

MAC address duplicado {{if .D.MACs}}{{len .D.MACs}}{{end}}

Mesmo MAC físico informado por registros diferentes. Causas comuns: Windows reinstalado (o registro antigo fica para trás), imagem clonada, ou adaptador compartilhado (dock/adaptador USB). Para a mesma máquina, clique em Manter este no registro correto — os demais serão mesclados nele. Se forem máquinas diferentes com adaptador compartilhado, ignore o MAC.
